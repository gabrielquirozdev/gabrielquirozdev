# About Me

Hello! My name is Gabriel. I'm an Industrial Engineer currently working as a backend developer focused on databases and data, and transitioning into Data Engineering. I come from a data analysis background, and today I work mostly on the backend and data side: modeling databases, building APIs and integrations, and developing the workflows that move and transform data between systems.

- Designing and modeling relational databases using SQL Server.
- Building backend services and REST APIs with Node.js and Express.
- Developing data integrations between ERP and e-commerce systems.
- Writing ingestion and data processing scripts in Python and SQL.
- Interested in modern data stack technologies.
